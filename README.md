# Puppy's JanitorAI Chat Themes
CSS injection browser extension to make your JanitorAI chats look nicer. Applies client-side only themes to the chat page. 
## Features

- Live previews
- Easy theme switching
- Background and text colour customization per theme


## Installation

### Web Store Installation
1. Install the extension from the Chrome Webstore (pending review).
2. Pin the extension to your 'Quick Access'

### Manual Installation (Chrome)
1. Download the extension zip from the Github Repo.
2. Unzip/Unpack the file 
3. Go to 'Manage Extensions' 
4. Turn On Developer Mode
5. Load Unpacked extension 
6. Pin the extension to your 'Quick Access'
